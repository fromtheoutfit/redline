# Tell the person when a resumable stop needs no hand fix before the relaunch

When a Redline run stops with an error it can resume from, the `/redline:redline` skill's error report (`skills/redline/SKILL.md`, section `error`) always says that once the cause is fixed by hand, `/redline:redline <n>` offers to resume from the stopped step, and that a hand fix touching anything outside `.claude/` means a fresh run. Two kinds of stop are the workflow's own check of what an agent returned and need no hand fix: an error that opens `the resolve agent ` (a stated or named disposition that the same resolve's tasks or entries cannot support, or a deferral with no entry, since #99 and #108), and an error that opens `the reshape left ` (a reshape that left a decided fix with no task, or a decided accept with one, since #106). For both, the resume line in `workflows/redline-loop.js` (`resumeLine`) tells the rerun agent that nothing was fixed by hand and to correct what it wrote, and `docs/running.md` tells the person "so nothing needs fixing by hand first". The skill still tells them to fix the cause first, so a person may edit `plan.md` in the spec folder by hand, or start a fresh run, when a plain relaunch was all the stop needed.

- **Where:** `skills/redline/SKILL.md:272`
- **Why it is not fixed in #114:** The report's wording predates the pull request it was found in. That pull request added one more stop of this kind, the hold of a decided finding to its task after a reshape, and did not set out to change the skill. The wording belongs with the whole class, the resolve-check stops included, as a change to the skill's error section of its own.
- **Proposed fix:** Have the workflow say in an error result that the stop is its own check of an agent's result, chosen where `resumeLine` already chooses its clause (an error opening `the resolve agent ` at a resolve step, or `the reshape left ` at a reshape), for example as a field beside `resumeFrom`, so the skill reads a field and never the error's words. Then, in the `error` section of `skills/redline/SKILL.md`, say for such a stop that `/redline:redline <n>` resumes from the step as it stands with nothing to fix by hand, and keep the current sentence for every other resumable stop. Add loop cases for a resolve-check stop, a reshape-hold stop and an ordinary stop, and pin both wordings of the skill by key phrase.
