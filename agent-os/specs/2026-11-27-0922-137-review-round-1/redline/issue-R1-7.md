# Name --plugin-dir in every reopen line for a run launched from a checkout loaded in place

A run launched from a checkout loaded in place (`claude --plugin-dir <checkout>`) can be resumed or relaunched only from a session that loads the same checkout, yet the lines that tell the person how to get back to the run's session say plain `claude --resume <session id>`: the `session` line of `redline-prefs.sh run check` (the `refuse session` call in `scripts/redline-prefs.sh` and its header), and in `skills/redline/SKILL.md` the resume's `session` reason in section 2, the stopped-run paragraph, the denied `scriptPath` relaunch, the closing sentence of "The script a relaunch runs" and the `error` section's resume line, with `docs/running.md` "Run markers and resume" and the README's Known limits bullet on resuming from the run's own session. A reopen without `--plugin-dir` runs the installed release instead (measured on Claude Code 2.1.332 with a throwaway plugin, m5 in the #135 spec), so the next command is refused for another version, or, at the same version, for another copy's agent files, and a run that could have been resumed is started fresh; and the version line of `run check` and `run drift` says to start fresh, which in a session that loads a checkout in place after its version changed is refused once more before the reopen advice comes.

- **Where:** `skills/redline/SKILL.md:275`
- **Why it is not fixed in #137:** These lines predate #135 (#10, #81), and closing them means a new form for `run check`'s `session` line with its prefs cases and header, and a reword in each of eight places in the skill, `docs/` and the README; PR #137 fixed only the advice its own change added, for a fresh launch the workflow refuses for its version.
- **Proposed fix:** Have `run check` print `claude --plugin-dir <args.pluginRoot> --resume <id>` in its `session` line when the marker's `args.pluginRoot` is not under `plugins/cache/` (a checkout loaded in place), with a prefs-test case for each form, have the version line say to reopen that way before starting fresh in the same case, and have each reopen sentence in the skill, `docs/running.md` and the README name the flag the same way, with the session's `${CLAUDE_PLUGIN_ROOT}` as the root where no marker gives one.
