# Internal notes

This is the public repository: it carries the tool and its operating documentation, never the design record.

- Step notes, spike notes, API notes and the design document live in the private sibling repository `redline-internal` (`DESIGN.md`, `docs/`). A spec here may cite one by file name; it never copies the text in
- `README.md`, `docs/` and `CONTRIBUTING.md` are the long-form documents here: the README for installation and use (what it is, requirements, install, quick start, the dials, the Files table, the git rules for agents, Known limits), `docs/` for the reference (setup, contract, running, guard, upgrading, scripts), `CONTRIBUTING.md` for developing, CI, the Docs step and releases. A rationale goes to the internal repository; a rule goes to a standard (#14)
- Seed PRs and their answer keys live outside this repository, so a reviewer cannot read the answers
- `agent-os/specs/` holds the specs of changes to this repository, including the rounds Redline runs on itself. They are public and carry no attribution and no private detail (no token, no cost figure, no person's name beyond a GitHub login where a decision names its owner)
- A baseline for a PR whose head has moved is measured on a throwaway draft PR at the old SHA, since the precheck requires HEAD equal to the PR head and a run on the real PR would see later comments in the known-finding check; the body is the original's with `Closes` changed so nothing is linked, and the PR is closed and its branch deleted afterwards. Once the original PR is merged, `main` contains the old SHA and a draft PR against `main` diffs the wrong history, so the base is the branch's last merged `main` commit (the second parent of its last merge of `main`), pushed as a second throwaway branch and deleted with the first; while the original is open, `main` stays the base (#79). Once the original PR has merged, its review-round spec folders are on the default branch too, and a coverage pass that follows the repository's own check-before-reporting rule reads them: the #817 rerun's pass read the merged PR's round decisions at call 91 of 112 (`SPIKE-72-NOTES.md` §10). So measure before the original merges, or audit what the pass read, by call index, from the fork's transcript. The fork's thinking is empty in the transcript, so the call order is the only evidence: count as independent only what it found before the first such read; an item whose file the fork first names after the read is not independent even when the whole-diff read came before it, and is recorded as open, not as found (#85). Probe scripts, runbooks and run-record copies live beside the spike note in `redline-internal/docs/` (spike #72)
